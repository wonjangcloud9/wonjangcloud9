## 지금 만드는 것

🐢 **vibing** — 먹은 걸 사진으로 남기고 친구와 같이 보는 감량 앱. 거북이 코치 "비비"가 잔소리를 합니다. 앱스토어 출시 준비 중.

<details>
<summary><b>만들어 둔 것</b></summary>

<br>

- 🦀 **[wonjangAgent](https://github.com/wonjangcloud9/wonjangAgent)** — 한국어 우선 자율 AI 에이전트. Rust 단일 바이너리
- 🌳 **[claude-tree](https://github.com/wonjangcloud9/claude-tree)** — Claude Code 세션을 git worktree로 나눠 여러 개 동시에 굴리는 CLI
- 🛡️ **[open-guardrail](https://github.com/wonjangcloud9/open-guardrail)** — LLM 앱용 가드레일. API 호출 0번, 0.1ms 안에
- 📏 **[harness-eval](https://github.com/wonjangcloud9/harness-eval)** — 하네스가 결과를 얼마나 바꾸는지 숫자로 보는 CLI

</details>
